## Fase 1 — Protección de Datos (ISO 27001 A.10)

### Punto 8 — Cifrado en tránsito (HTTPS/TLS)

**Cambio de código:** `next.config.ts`
- Agregar header `Strict-Transport-Security` (HSTS, max-age 1 año, includeSubDomains)
- Agregar redirect permanente (301) HTTP → HTTPS

**Documentación:** `docs/iso27001/fase-1-punto-8-cifrado-transito.md`
- Configuración TLS en EasyPanel (Let's Encrypt automático via Traefik)
- Redirect HTTP → HTTPS en Next.js
- TLS en conexiones Supabase (toda conexión es TLS 1.2+ por defecto)
- Evidencia: extracto de config `next.config.ts`, referencia a EasyPanel y Supabase docs

### Punto 9 — Cifrado en reposo

**Sin cambio de código** — Supabase y Contabo manejan esto a nivel de infraestructura.

**Documentación:** `docs/iso27001/fase-1-punto-9-cifrado-reposo.md`
- Cifrado AES-256 de Supabase (PostgreSQL + Storage) con referencias a documentación oficial
- Política de cifrado de Contabo VPS
- Aclaración: el código de la aplicación no necesita implementar cifrado adicional en reposo
